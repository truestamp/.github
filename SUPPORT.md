# Getting Help

- **Questions:** search or ask in [Discussions](https://github.com/orgs/truestamp/discussions/categories/q-a).
- **Using Truestamp:** the [help center](https://www.truestamp.com/support) has the knowledge base, API docs and FAQ, or email [support@truestamp.com](mailto:support@truestamp.com).
- **Bugs:** open an issue in the relevant repository, or in [truestamp/discussions](https://github.com/truestamp/discussions/issues/new/choose) if you're not sure which.
- **Ideas and feedback:** the [feedback board](https://truestamp.userjot.com/board/features).
- **Security vulnerabilities:** report privately, as described in the [security policy](https://github.com/truestamp/.github/blob/main/SECURITY.md).
